Google Form connection test

Open this file directly from your computer (double-click it). Nothing else on the page — no framework, no build, no CSP — so if a submission lands in your form's Responses tab from here, the endpoint and field name are correct and any failure elsewhere is that page's sandbox, not your form.

Run Test A, then check your form's Responses tab.

Test A posts into a hidden frame exactly the way the landing page does — the page stays put, so the only proof is a new row in Responses.
Test B submits the same data in a new tab so you actually see Google's reply. If it shows "Your response has been recorded", the form accepts the post and the landing page will too. If it shows an error page, the problem is on the form's side and the message will say which.
